# MSTI Coffee Chat Program — Email Templates

This directory contains all email draft templates used in the Coffee Chat coordinator dashboard.

## Templates

| File | When it's sent | Recipient(s) |
|------|---------------|--------------|
| [01-intro-email.md](01-intro-email.md) | After coordinator assigns an ambassador | Student + Ambassador |
| [02-feedback-email.md](02-feedback-email.md) | After chat is marked completed | Student only |

## Notes

- `[STUDENT_FIRST]`, `[AMB_FIRST]`, `[AMB_NAME]` etc. are placeholder variables — the dashboard fills these in automatically from the request data.
- Coordinators can edit the email content directly in the dashboard before sending.
- All emails are sent with the GIX/MSTI email signature appended automatically.
